# Tic Tac Toe

A simple browser-based Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- Interactive game board
- Win and draw detection
- Restart game option
- Responsive, easy-to-use interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the `Tic Tac Toe` folder.
3. Open `index.html` in any web browser.

## Project Structure

```text
Tic Tac Toe/
├── index.html
├── style.css
└── app.js
```

## Preview

Choose either **X** or **O** on your turn. The game automatically announces the winner or a draw when the match ends.
