# Rock Paper Scissors Game

A simple interactive Rock Paper Scissors game built with JavaScript. Select Rock, Paper, or Scissors, and the computer randomly makes its choice. The app immediately shows the round result and updates both scores.

## Features

- Play against a computer opponent
- Random computer choice generation
- Live user and computer score tracking
- Win, lose, and draw result messages
- Color-coded result feedback
- Click-based game controls

## Concepts Used

- Variables and score tracking
- Functions and arrow functions
- Arrays
- Conditional statements
- Template literals
- DOM selection and manipulation
- Event listeners
- `forEach()` iteration
- Random number generation with `Math.random()` and `Math.floor()`

## How It Works

1. The player clicks Rock, Paper, or Scissors.
2. JavaScript reads the player's selected choice.
3. The computer randomly selects one of the three options.
4. The game compares both choices.
5. The result message is displayed.
6. The appropriate score increases when there is a winner.

## Technologies Used

- HTML
- CSS
- JavaScript

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Choose Rock, Paper, or Scissors to start playing.
